# Hi, I'm Abeer Ilyas

### Computer Vision and AI Engineer · Project Lead

I build production computer vision systems in Python and PyTorch: self-hosted pipelines that combine object detection, OCR, and vision-language models, with no third-party API dependency and client data kept on-premise.

## What I work on

**Document and drawing analysis.** Detection, OCR, and vision-language pipelines that run unattended in production, including vector geometry parsing and tag extraction for technical drawings.

**Model serving and reliability.** GPU memory gating, per-request checkpointing, and a vLLM migration that cut a four-document batch from 6 minutes to 2.

**Edge and aerial detection.** YOLO training and benchmarking for real-time edge deployment and UAV vehicle detection.

## Research

First author of **"Deep Learning Application for Vehicle Detection through Surveillance Drones"**, presented at IEEE ICECET 2024. It benchmarks YOLOv8, Faster R-CNN and SSD under domain shift and releases the Pak Vehicles UAV dataset.

[Paper (DOI)](https://doi.org/10.1109/ICECET.2024.10698500) · [Code](https://github.com/4833R11Y45/Vehicle-Detection-using-YOLOv8-Faster-R-CNN-and-SSD)
